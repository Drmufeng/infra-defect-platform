# Training 目录说明

`training/` 现已收缩为统一训练工作区，用于隔离训练实验代码与后端服务代码，避免多模型方向扩展时结构继续发散。

## 当前目录结构

- `training/tasks/`：按任务方向组织训练内容
- `training/shared/`：不同任务可复用的工具、数据处理与评估逻辑

## 当前已落地任务

- `training/tasks/crack_detection/`：道路裂缝检测训练工作区

## 设计原则

- 训练代码与后端服务彻底隔离
- 训练脚本、配置、权重、报告按任务统一归档
- 后续若增加坑槽检测、多病害检测，可直接在 `training/tasks/` 下新增任务目录
