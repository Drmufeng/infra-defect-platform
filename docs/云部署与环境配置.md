# 云部署与环境配置

本文档用于说明项目在本地开发、Docker 部署和云服务器部署时的推荐配置方式，避免把本机路径、端口和账号密码写死在代码中。

如果你需要按步骤在云服务器上实际落地，请优先参考：`docs/云服务器部署流程.md`

## 一、当前默认端口

- 管理端：`5500`
- 客户端：`5180`
- 后端：`2048`
- PostgreSQL：`5432`

说明：以上端口仅作为本地默认值，后续上云时可通过环境变量覆盖。

## 二、环境变量文件

推荐使用以下示例文件作为模板：

- 后端：`apps/api-server/.env.example`
- 管理端：`apps/admin-web/.env.example`
- 客户端：`apps/client-web/.env.example`
- Docker Compose：根目录 `.env.example`

建议复制后再按实际环境调整：

```bash
copy apps\api-server\.env.example apps\api-server\.env
copy apps\admin-web\.env.example apps\admin-web\.env.development.local
copy apps\client-web\.env.example apps\client-web\.env.development.local
copy .env.example .env
```

## 三、本地开发推荐方式

### 1. 后端

在 `apps/api-server/` 目录下执行：

```bash
python -m app.db.init_db
uvicorn app.main:app --host 127.0.0.1 --port 2048 --reload
```

若在项目根目录执行，推荐：

```bash
.venv311\Scripts\python.exe -m uvicorn app.main:app --app-dir apps/api-server --host 127.0.0.1 --port 2048 --reload
```

### 2. 管理端

```bash
cd apps/admin-web
npm install
npm run dev
```

### 3. 客户端

```bash
cd apps/client-web
npm install
npm run dev
```

## 四、Docker 部署骨架

当前项目已提供：

- `docker-compose.yml`
- `apps/api-server/Dockerfile`
- `apps/admin-web/Dockerfile`
- `apps/client-web/Dockerfile`
- `deploy/nginx/spa.conf`

本地或云服务器可直接执行：

```bash
docker compose up --build -d
```

默认暴露端口：

- `5500 -> admin-web`
- `5180 -> client-web`
- `2048 -> api-server`
- `5432 -> postgres`

## 五、云服务器部署建议

- 建议使用 Linux 服务器（Ubuntu 22.04 / Debian 12）
- 建议通过 `Nginx + Docker Compose` 管理服务
- 建议为以下内容使用环境变量或密钥管理：
  - `POSTGRES_PASSWORD`
  - `AUTH_SECRET_KEY`
  - `INITIAL_ADMIN_PASSWORD`
  - `DATABASE_URL`
- 建议将 `storage/`、`datasets/`、`training/` 挂载到独立数据盘或对象存储同步目录
- 建议将管理端和客户端通过域名访问，后端通过反向代理统一转发 `/api`

## 六、上线前建议补齐项

- 将 Swagger 文档静态资源本地化，避免依赖外网 CDN
- 增加 `.env.production` 和部署专用配置说明
- 增加数据库备份策略与模型权重备份策略
- 补充 HTTPS、域名、Nginx 反向代理配置说明
- 关闭生产环境默认管理员密码，改为首次部署强制设置
