- 数据集名称：RDD2022 中国子集
- 原始压缩包位置：
  - `datasets/raw/RDD2022_China_MotorBike.zip`
  - `datasets/raw/RDD2022_China_Drone.zip`
- 原始解压目录位置：
  - `datasets/raw/RDD2022_China_MotorBike/`
  - `datasets/raw/RDD2022_China_Drone/`

说明：`datasets/raw/` 中的数据视为原始数据，不直接修改。

## 二、处理版本记录

### v1

- 任务方向：道路裂痕检测
- 数据来源：仅使用 `China_MotorBike` 训练集
- 标签策略：将 `D00`、`D10`、`D20` 合并为 `crack`
- 是否包含无人机数据：否
- 处理后数据目录：`datasets/processed/rdd_china_crack_only_v1/`
- 训练配置文件：`training/tasks/crack_detection/configs/rdd_china_crack_only_v1.yaml`
- 训练脚本：`training/tasks/crack_detection/scripts/train_rdd_crack_v1.py`
- 备用训练脚本：`training/tasks/crack_detection/scripts/train_rdd_crack_v1.bat`
- 预期模型输出目录：`training/tasks/crack_detection/weights/rdd_china_crack_only_v1/`
